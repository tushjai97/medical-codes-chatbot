Recall@5 — full test set vs. procedure-only subset

7 of 10 test cases expect generic E&M visit codes (99213/99214) for diagnosis-only queries with no procedure mentioned — no embedding model can infer those from diagnosis text alone. Isolating the 3 genuinely procedure-based cases (knee arthroplasty, aortic aneurysm repair, finger amputation) shows what retrieval quality actually looks like when the query matches the code type's vocabulary.
